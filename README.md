## 1. 正则化、归一化与标准化

### （1）概念

- **正则化**：在损失函数中添加“惩罚项”，用来限制模型参数的复杂度，防止模型过拟合
- **归一化**：将数据缩放到一个特定范围，通常是[0,1]

### （3）正则化方法

- **L1范数正则化**：有一大串公式，后面的||w||1表示向量里每个数绝对值相加；线性；可能有0惩罚消失
- **L2范数正则化**：公式前面与L1同，后面的||w||22表示数字平方和相加再开根；不会出现极端数据
- **L0范数正则化**：L0范数不连续，一般用L1

ps：L1有额外好处，它更容易获得“稀释”解，w非零分量更少（但用等值线解释的部分没有看懂）；但L2更常用
