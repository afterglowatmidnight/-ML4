## 1. 正则化、归一化与标准化

### （1）

- **正则化**：在损失函数中添加惩罚项，用来限制模型参数的复杂度，防止模型过拟合
- **归一化**：将数据缩放到一个特定范围，通常是[0,1]；尺度统一；对异常值敏感
- **标准化**：将数据变换为均值为 0、标准差为 1 的分布；使不同变量的数据具有可比性；受异常值影响但不极端

**三者区别**：

- 正则化防止模型学得太多导致过拟合，与下面两个概念区别较大
- 归一化是调整数据范围，让数据落在统一区间，适合神经网络和图像（因为天然0~255)；有边界
- 标准化是调整数据分布，让数据围绕 0 附近分布；无边界

### （2）

- 原因：可以消除量纲差异，让不同特征可以相互比较；优化梯度下降，更稳定；保证基于距离的算法正常工作
- 影响：模型几乎只根据数值大的特征做判断，小数值特征被忽略；数值不稳定；正则化的效果被削弱

### （3）

- **L1范数正则化**：有一大串公式，后面的||w||1表示向量里每个数绝对值相加；线性；可能有0惩罚消失
- **L2范数正则化**：公式前面与L1同，后面的||w||22表示数字平方和相加再开根；不会出现极端数据
- **L0范数正则化**：L0范数不连续，一般用L1

ps：L1有额外好处，它更容易获得“稀释”解，w非零分量更少（但用等值线解释的部分没有看懂）；但L2更常用

### （附加）

过拟合出现的原因是模型学习得太好，把非基本数据也当成了某个事物的特征，本质上是把极端数据当成正常数据的一部分；

而正则化添加惩罚项限制了参数幅度，数据中不会出现极端的异常值，拟合效果变好

## 2. 神经网络

### (1)

个人认为反射弧比神经元结构更适合比喻：一个基本的神经网络通常由输入层（like 感受器+传入神经）、隐藏层（like 神经中枢）和输出层（like 传出神经+效应器）组成。

- **输入层**：神经网络的第一层，将输入数据转化为神经网络内部可以处理的格式（接收）
- **隐藏层**：位于输入层与输出层之间的一层或多层，将输入数据转换为更高层次的特征表示（加工）
- **输出层**：最后一层，给出网络的最终结果，二分类常用一个神经元加 Sigmoid，多分类常用多个神经元加 Softmax，回归则常用线性输出（回答）

### (2)

上层节点的输出和下层节点的输入之间的一个函数关系（在下层神经元内部）；用来引入非线性因素，使得神经网络表达能力更强。

Typical ones:

- **Sigmoid**：压缩到0~1；多用于二分类输出层；有指数运算，较慢
- **Tanh**：压缩到-1~1；过去多用于隐藏层；非线性映射能力强；有指数运算，较慢
- **ReLU**：负数截断为0，正数原样输出；隐藏层最常用激活函数；无指数运算，极快
- **Leaky ReLU**：给负区间一个小斜率，避免 ReLU 的神经元死亡，同时保留其正区间优点
- **ELU**：同样解决Dead ReLU，负数部分用指数函数，平滑饱和；计算开销大

### (3)

因为神经网络需要激活函数来引入非线性因素。

如果网络中的所有层都不使用非线性激活函数，会产生的问题：

- **无法拟合复杂关系**：现实中的很多问题都是非线性的，如果没有非线性激活函数，网络再深，也只能画一条直线来分割数据，该网络将无法理解世界
- **深度失去意义**：一般来说，浅层学简单特征（边缘、纹理）、中层学组合特征（形状、部件）、深层学抽象特征（物体、语义），但如果每层都是线性的，那么：深层 = 浅层 = 单层

### (4)

主要原因：

- **梯度消失 / 梯度爆炸**：梯度在反向传播中越来越小，接近 0，参数几乎不更新 / 或梯度越来越大，参数更新过猛，训练发散

  ps：在此查询了**梯度**的概念：即损失函数对参数的变化率，指示参数往哪个方向调、调多少，损失下降最快

- **退化问题**：网络层数过多时，新增层难以学习恒等映射，训练集准确率也会下降

  ps：在此查询了**恒等映射**的概念：函数输出等于输入，不对数据做任何变换

- **过拟合**

### (5)

- **训练集**：用来学习模型参数，让模型从数据中拟合规律
- **验证集**：检验模型的性能，帮助选择最佳模型参数
- **测试集**：评估模型的泛化能力，给出最终性能报告

  ps：在此查询了**泛化能力**的概念：模型在没见过的新数据（测试集）上的预测能力

就像考试就直接考你平时的作业题一样，如果简单地使用同一份数据完成模型训练和最终性能评估，那么最终结果会拟合效果非常好，没有办法发现过拟合等缺陷。

## 3.损失函数与优化算法

### (1)

损失函数是用来度量模型预测值f(x)与真实值Y之间差异程度的运算函数。（理解：在模型每次做出预测后，它都会给这个预测打分，分数越高，代表预测差异越大；分数越低，代表预测越准确）

损失函数会计算出预测值和真实值之间的差异值（即损失值），通过反向传播更新各个参数，降低真实值与预测值之间的损失，来让模型预测值更接近真实值。

### (2)

因为不同问题类型（回归，分类）和数据特性（有无异常值）需要不同的损失函数。

分类任务中：

- **交叉熵损失**：预测越接近真实类别，损失越小
- **Hinge Loss**：用于支持SVM类的分类任务；不适合多分类

  ps：在此查询了**SVM**的概念：分类算法，找一条分界线让两类数据之间的空隙尽可能宽，提高泛化能力

回归任务中：

- **均方误差(MSE)**：个人认为和高中数学的方差概念相似（残差平方和除以n）；对误差平方，因此对异常值非常敏感，可能导致过拟合
- **平均绝对误差(MAE)**：残差绝对值之和除以n；对异常值不敏感
- **Huber 损失**：结合以上两种的优点

### (3)

梯度是一个向量（偏导，但我还没学会这个数学东西），它指向损失函数的函数值(Loss)增长最快的方向，其方向指向函数值上升最快的方向、大小表示该方向上的变化率（陡峭程度）、负梯度方向指向函数值下降最快的方向。

### (4)

沿着损失函数下降最快的方向，一步步调整参数，直到损失达到最小值。

如何更新：

- ①前向传播：引入旧参数，算出损失
- ②反向传播：求损失对每个参数的梯度
- ③对每一个参数单独更新
- ④替换参数，重复循环
